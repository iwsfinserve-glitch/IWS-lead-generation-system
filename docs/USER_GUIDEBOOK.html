IWS Lead Management System

The complete operational guide and feature reference manual for Wealth Management, Financial Advisory, and High-Velocity Sales Teams.

1. System Overview & Architecture

The IWS Lead Management System is an end-to-end client relationship management platform designed to accelerate sales pipelines from multi-channel intake through AI qualification, omnichannel communication, and closing.

1
FastAPI High-Speed Core
Asynchronous Python backend with SQLAlchemy 2.0, PostgreSQL connection pooling, and background task schedulers.
2
Modern React 18 SPA
Client-side routing with Vite, real-time optimistic state updates, glassmorphism design, and dark mode ergonomics.
3
Gemini AI Intelligence
Automated lead scoring (0–100), win probability modeling, optimal contact timing, and customized talking points.

2. Role-Based Access Control (RBAC) Matrix

System features and data access are partitioned across three organizational tiers:

Feature / Action Sales Rep Sales Manager System Admin
View Assigned Leads & Clients ✅ Own Leads ✅ All Team Leads ✅ System-Wide
Claim Unassigned Leads ✅ Allowed ✅ Allowed ✅ Allowed
Lead Status Stage Advancement ⚠️ Submit Request ⚡ Instant Update ⚡ Instant Update
Approve Status Update Requests ❌ No Access ✅ Full Access ✅ Full Access
Team Performance Dashboard (/my-team) ❌ No Access ✅ Subordinates ✅ All Users
Omnichannel WhatsApp Inbox & Widget ✅ Assigned ✅ Full Access ✅ Full Access
User Provisioning & Role Management ❌ No Access 👁️ View Only ✅ Create / Edit / Deactivate

13. Troubleshooting & FAQ

❓
Q: Why does a Sales Rep need approval to convert a lead?
A: To prevent reporting discrepancies and ensure full compliance/KYC documentation before moving deals into the closed investor ledger.
💡
Q: How do I export my clients for offline review?
A: Go to /leads, select the My Clients tab, and click Export CSV in the upper right toolbar.
